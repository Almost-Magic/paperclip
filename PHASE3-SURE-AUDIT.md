- ✅ Rate limiting middleware (10 req/min per IP)
- ✅ Authentication on 8+ endpoints (get_current_user dependency)
- ✅ Error handling with HTTPException (20+ uses)
- ✅ SQL injection prevention (parameterised queries with :param)
- ✅ Input validation (Pydantic schemas)
- ✅ CORS ready (can enable via middleware)

**What Could Improve Score:**
- WebSocket auth (currently relies on HTTP token, not WebSocket auth token)
- HTTPS enforcement (not configured in FastAPI, done via NGINX)
- Rate limiting is in-memory (single process, would need Redis for distributed)
- Audit logging doesn't capture failed auth attempts (minor)

**Score Rationale:** 11/20 reflects good security posture with minor recommendations above.
