# Paperclip Phase 3 — Advanced Features & Optimization

## Scope

Build cost tracking, audit logging, and advanced dashboards on top of Phase 2's foundation.

## Deliverables

### F1: Cost Tracking (LLM + Infrastructure)
- Track costs per task (estimate based on LLM model + tokens)
- Aggregate costs by terminal, hand, user, time period
- Cost forecasting based on current run rate
- Budget alerts when threshold exceeded
- Database: `cost_ledger` table with cost_cents, model, provider fields

### F2: Audit Logging
- Log all user actions (create task, set preference, login, etc.)
- Log all system changes (terminal status, routing decision, etc.)
- Audit trail queryable by user, action, resource, timestamp
- Compliance ready (GDPR-friendly)
- Database: `audit_log` table with user, action, resource, timestamp, changes

### F3: Advanced Dashboard
- Cost trend chart (last 7/30 days)
- Terminal utilisation heatmap
- Top tasks by duration/cost
- Audit log viewer (recent actions)
- Alert summary panel

### F4: Performance Optimization
- Query optimization (add missing indexes)
- Cache frequently-accessed data (Redis optional)
- Task archival (move old tasks to archive table)
- Database cleanup jobs

### F5: Reporting API
- `GET /api/reports/cost-summary` — costs by period/agent
- `GET /api/reports/utilisation` — terminal/hand utilisation rates
- `GET /api/reports/audit-log` — filtered audit events
- `GET /api/reports/forecasting` — cost forecast (trend)
